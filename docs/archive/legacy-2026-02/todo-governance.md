# Governance

## Decision-making
- Propose changes via GitHub issues.
- Discuss and resolve in the linked PR.
- Record the decision in the PR description and merge commit.

## Publishing rules
- All content changes go through PR review.
- One reviewer minimum for pages; two for posts or brand changes.
- Ensure links, dates, and claims are verified before merge.

## Security notes
- Do not include client secrets, internal data, or private names.
- Avoid revealing internal governance, equity, or commercial terms.
- Report sensitive issues via a private channel, not public issues.
